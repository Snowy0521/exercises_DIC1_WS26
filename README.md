## A Recommendation

I strongly recommend that you work through the tasks of each exercise **before** the session, on your own or with your partner. From previous years' experience, students who follow this rule tend to get **higher scores** in the final exam.

This is entirely voluntary and not a requirement.

- **Option 1 – Git (recommended):** clone the repository once:
  ```bash
  git clone https://github.com/Snowy0521/exercises_DIC1_WS26.git
  ```
  After each new release, run this inside the folder to get the latest solution:
  ```bash
  git pull
  ```
- **Option 2 – ZIP download:** on the repository page, click **Code → Download ZIP**. You need to download it again after each new release.

## How to Read the Solutions

All solutions are written in Markdown. GitHub's built-in Markdown renderer has limited support, so some content (e.g. advanced Markdown syntax, mathematical formulas) may not display correctly on GitHub.

For the best reading experience, view the files locally in **Visual Studio Code** with the **Markdown Preview Enhanced** extension:

1. Download and install Visual Studio Code: https://code.visualstudio.com/
2. In VS Code, install the extension **Markdown Preview Enhanced**.
3. Get the solutions (see [How to Get the Solutions](#how-to-get-the-solutions)).
4. Open any `.md` file and use the extension's preview.

## FAQs

**How is this solution different from the official solution?**

My solution is the slide I use in the exercise session, and it shows how I approach each task. Compared with the official solution, it goes into more detail on some tasks, for example by including the full derivation of formulas, so it is longer but with same final answers. I recommend using both together.
